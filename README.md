# 太阳系漫游 / Solar System Explorer

Godot **4.6.3 stable**、带类型标注的 GDScript、Compatibility 渲染器。
目标平台为 Android 与 iPadOS / iOS；当前优先交付安卓平板体验。

- 修复重复点击已选行星后外框消失的问题；首次主动点击全景中默认选中的地球会记录探索足迹，重复选择保持安静。

## 运行

启动进入“出发”页。首次进入探索显示太阳系全景，模拟默认暂停；“继续探索”进入上次选中行星的近景，行星选择保存在本机。顶部扬声器开关同时控制背景音乐和点击音效，并记住静音偏好。

在 Godot 中导入 `project.godot`，按 F5 运行。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --editor --path /Users/penn/Projects/solar-system-explorer
```

桌面拖动场景旋转、滚轮缩放；点击场景行星进入近景，下方缩略图用于选择行星。“近景”跟随目标，“全景”返回轨道总览，“恢复视角”恢复当前视图的默认相机。
移动设备使用单指旋转、双指缩放。相关代码已接入，实际触控仍待设备验收。

## 模型边界

天体纹理使用 NASA 与 Solar System Scope 的影像/艺术地图，并做视觉增强；不是实时影像或测量地图。探索视图缩放了天体尺寸和轨道间距。
轨道使用固定、共面的椭圆和任意初始相位；不采用真实历元、轨道倾角或摄动，不是实时星历。
公转周期和自转周期来自 JPL，统一模拟时钟保留周期关系；探索视图未实现真实轴倾角，四季实验单独使用约 23.4° 倾角教学模型。
月球采用约 27.3 天的圆轨道示意，未实现精确地月系统、月相或日月食。

## 代码结构

- `scripts/app.gd`：导航、资料卡、实验交互、布局和生命周期。
- `scripts/solar_system.gd`：天体场景、选择、模拟与渲染。
- `scripts/orbit_camera.gd`：相机跟随、拖拽和缩放。
- `scripts/catalog.gd`、`data/planets.json`：参数校验、开普勒计算与数据来源。
- `scripts/learning_canvas.gd`：教学与比例比较视图。
- `scripts/progress_store.gd`：版本化本地记录、原子写入、损坏恢复。
- `scripts/app_activity.gd`：分别跟踪焦点与系统暂停状态，协调前后台行为。
- `scripts/ui_audio.gd`：点击音效、循环背景音乐、静音偏好和播放生命周期。
- `assets/shaders/planet.gdshader`：表面贴图与日照明暗；`clouds.gdshader` / `atmosphere.gdshader` 实现云层与大气。
- `tests/run_tests.gd`：轨道、存储、流程与布局检查。
- `tests/interaction_polish_tests.gd`：行星选择、实验输入与滚动、知识卡导航回归。
- `docs/RELEASE_V0.21.0.md`：本轮交付状态、限制和下一步验收。
- `docs/DEVELOPMENT_PLAN.md`：原始路线及当前阶段说明。

数据来源保存在 JSON 与应用的“资料与说明”中。外部素材署名和许可详见 `docs/ASSET_CREDITS.md`，也可在应用内查看；引擎使用 Godot MIT 许可。
