# v0.2.0 开发版交付记录

日期：2026-10-08。优先验收平台：安卓平板（用户已确认，型号待确定）。

## 交付内容

已从日地月工程骨架扩展为四个入口的完整体验路径：出发 → 八大行星探索 → 行星资料与近景 → 实验室 → 大小／距离比较。
可在探索中暂停和调整时间，拖动相机、选择天体、近距离跟随，返回全景。
两项实验提供滑杆与解释反馈，浏览记录及实验完成状态保存到本地。
所有核心素材和数据随应用提供，不要求网络或账号。

## 数据和科学表达

体积等效平均半径、恒星自转／公转周期来自 [JPL 物理参数](https://ssd.jpl.nasa.gov/planets/phys_par.html)。
半长轴与偏心率采用 [JPL J2000 拟合轨道参数表](https://ssd.jpl.nasa.gov/planets/approx_pos.html) 的初值。
元数据说明字段单位、定义、来源和校对日期；地球轨道以地月质心近似。
轨道初始相位任意，轨道共面且固定，不是真实日期的天体位置。程序化颜色和纹理不作为地图。
月球的约 27.3 天公转周期参考 [NASA 月球资料](https://science.nasa.gov/moon/facts/)，仅作简化地球专题展示。

## 验证情况

通过：

- 8 个行星数据条目与 24 项轨道闭合、近日点和远日点检查。
- 暂停时钟、行星选择与相机跟随、离开实验后保留探索时间。
- 0°／90°／180° 的昼夜状态、错题解释、完成状态保存。
- 重复浏览不重复计数、记录重载、损坏文件备份与恢复。
- 平板横屏、平板竖屏及 390 × 844 手机窗口的实际渲染检查。
- APK 的启动入口、ARM64 架构、离线数据、开发文件排除、ZIP 完整性和调试签名校验（见构建校验报告）。

- iPad / iPhone 的团队签名、开发包、真机验收。
- 商店发布、正式包名和发布签名。

## 构建

`builds/android/solar-system-explorer-v0.2.0-debug.apk` 为 ARM64 调试安装包。
最低 API 24、目标 API 36、OpenGL ES 3.0。这些来自构建清单，不表示已在所有符合条件的设备上测试。
使用现有本地 JDK 17、Android SDK 和 Godot 4.6.3 导出模板；没有上传商店或生成发布证书。
Android 预设显式启用应用列表入口，且不请求 Android 权限。

构建：`./tools/build_android.sh`。
校验：`python3 tools/verify_android.py builds/android/solar-system-explorer-v0.2.0-debug.apk`。

## 已知限制与后续工作

- 视觉目前以程序化模型为主，后续增加经审核的天体纹理、月球详情与分辨率分档。
- 镜头是即时跟随；平滑过渡、双指平移、标签避让、完整的减弱动态和读屏体验尚待实现。
- 手机使用纵向滚动布局，还不是最终的底部导航与双档抽屉交互。
- 真实轴倾角、精确地月模型、四季、月相及日月食不在此版实现。
- 在高速模拟下自转可能产生视觉采样混叠，应通过独立自转实验理解运动；不据此判定真实方向。
- iOS 未验证，不能将 Android 构建结果当作双端验收通过。

下一步先在目标安卓平板安装此版本，检查中文字体、图形兼容性、双指缩放、横竖屏、返回与后台恢复，并记录 15 分钟运行的帧率、内存和温升。随后完善视觉资源与移动端交互。
