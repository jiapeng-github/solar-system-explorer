# v0.3.1 行星显示与太阳系全景优化

## 本次改动

- 显示轨道半长轴由 4～22.55 调整到 12～140 个场景单位：12、24、38、53、71、91、114、140。外侧轨道逐级增加间隔；真实 au 参数与公转周期保持原值。
- 相机根据轨道范围和视口宽高自动取景，并扩大远裁剪和缩放范围。全景放大较小天体以保证可辨认性，选中轨道及标签使用浅青色。
- 全景标签按投影位置避让；点击行星直接进入近景。
- 近景只显示当前行星（地球保留月球，土星保留环），隐藏无关天体与轨道线。依据视口宽高、行星半径、土星环外径计算取景距离；返回全景后恢复显示。
- 全景页标题和操作提示随视图切换。

显示比例仍是科普示意，不是实际距离或实际大小比例；精确比较请使用“比较”页。
