# v0.21.0 · 全界面巡检与交互修正

本轮检查覆盖出发、探索全景与近景、三个实验、四种比较模式、八行星知识卡、学习进度及答题/资料/重置弹层，保留现有深蓝与青色视觉方案。

## 修正

- 重复点击已选行星后，选中边框保持显示。首次主动点击默认地球会记录探索足迹，之后的重复选择不重复记数或发声。
- 知识卡保持“探索”导航高亮；地球提供“与木星比较”，避免与自身比较。其他行星继续与地球比较。
- 知识卡和比较页的“返回探索”会消耗对应返回路径，系统返回键不会再打开刚离开的页面。
- 切换不同实验从顶部开始；离开后回到同一实验保留滚动位置。昼夜时间轴的键盘调整与触摸拖动都会先暂停播放，避免手动值被动画覆盖。
- 应用焦点和系统暂停状态分别保存；两项条件都解除后才恢复音乐和探索渲染，避免系统通知交错时提前播放。实验动画保持暂停，等待用户继续。
- 四季实验拖动中即时更新画面和内存记录，在释放、切页或进入后台时保存；完成记录一起保存。回归检查验证 180 次拖动更新没有同步写盘，释放时一次落盘。
- 保存成功会清除旧错误；写入/刷新失败不替换上一份完整记录。读取缺失或损坏文件时恢复默认内存数据，损坏文件保留备份。已完成实验不重复写盘。
- 更新启动方式、Logo、实验数量及音频接入状态的旧文档描述。

## 验证

13 组检查通过，最终日志无脚本错误或资源残留警告：基础流程、实际按键交互、存盘、生命周期、实验音效、全页音效、循环音乐、答题焦点、四季、公转、出发、进度和全界面巡检。

界面巡检涵盖 1280×800、1280×720、800×1100、390×844 四种窗口尺寸，每种检查 12 个页面状态，并补查手机页面底部和弹层。未发现页面横向溢出或平板主页面高度溢出；知识卡及手机长内容使用滚动。

音频与生命周期逻辑采用隔离的测试文件和可控通知，覆盖先恢复焦点/先恢复系统、重复通知、静音偏好、淡入、结果音压低背景音乐及 60 秒循环边界。图形布局和键盘焦点使用桌面渲染验证。所有测试与用户的本机学习记录、声音设置隔离。

详细结果见 `AUDIT_VERIFICATION_V0.21.0.json`，截图保存在 `work/audit-v021-*.png`。
