# v0.11.1 · 四季实验视觉精修

依据用户提供的四季概念图，精修实验室“四季与地轴”。

- 将主标题、说明与实验切换收进左栏，右侧指导卡片从页面顶部贯穿到底部。
- 实验、半球与倾角采用连续分段选择框；步骤使用圆环编号，统一青色主按钮与描边按钮。
- 加入独立季节标签、太阳图标、白昼“更长／更短”和正午太阳“更高／更低”提示；保留计算数值。0° 对照显示“不变”。
- 调整轨道为细虚线，增加地轴参考虚线、倾角弧、N/S 标注与选中地球光圈。地轴和朝向太阳的光照仍由统一物理方向计算。
- 地球加入云层与蓝色大气边缘；太阳使用独立程序纹理与柔和光晕，避免影响其他页面材质。
- 光照对照区增加独立边框、接收面示意和解释。底部横排时间轴、播放与重置；手机自动纵向排列。

验证
- Godot 4.6.3 实际渲染：1280×800、1280×720 横屏首屏和390×844手机宽度检查。
- 四季测试：南北半球定性提示与数值同步、0°对照、科学模型、进度完成门槛、暂停、时间轴终点、保存恢复和清除记录。
- 全应用回归：旧实验、探索、比较与学习记录。
- Android arm64 调试包：版本、启动入口、权限、离线资源、太阳/地球着色器、ZIP 完整性与签名校验。

说明
实际运行截图为本次交付依据；程序实时渲染与概念图的绘画质感仍有差异。大小和距离为教学示意，不对应具体年份；模型不推算当地气温。Android 平板真机性能与触控验收待进行。
