# v0.20.0 · 《星海慢航》背景音乐

已将用户确认的 60 秒原创背景音乐接入 App。使用循环原版，保留 PCM16 / 48 kHz / 立体声数据和原始首尾接缝；试听版及设计资料不进入安装包。

- 默认开启，在启动时约 1.5 秒柔和淡入；音乐播放器额外衰减 7 dB。
- 常驻播放器贯穿出发、探索、三个实验、比较、知识卡和进度页。切页不重启、不创建第二个音乐播放器。
- 沿用顶部声音开关，同时控制背景音乐和点击音效，兼容已有本机静音偏好。重置学习记录不影响声音设置。
- 静音或进入后台立即暂停输出并保留位置；开启声音或回前台后从暂停位置淡入续播。在后台开启声音不会立即播放。
- 正确、重试和首次完成等结果提示出现时，音乐短暂降低 4 dB；提示结束后平滑恢复，原有点击音效优先级不变。
- 背景音乐使用独立 Music 总线，两个点击/结果播放器继续使用 UI_SFX。无网络依赖或新增权限。

## 验证

背景音乐专项测试覆盖：60 秒循环实际跨越边界、1.5 秒淡入、结果音压低与恢复、所有页面及实验间播放器复用、静音位置保持、重启时读取静音偏好、重置记录不取消静音、Android 暂停/恢复，以及重复前台通知不重复淡入。

继续运行音效服务、实验室音效和全页音效联动回归。专项测试使用独立的学习、画质与声音偏好文件。结果摘要见 `MUSIC_VERIFICATION_V0.20.0.json`，安装包校验见 `BUILD_VERIFICATION_V0.20.0.json`。

版本 0.20.0，Android versionCode 27，arm64 debug APK。Android 平板扬声器与耳机的实际响度和延迟仍待真机试听；桌面验证不替代设备验收。

四组验证均通过，最终日志无脚本错误或资源残留警告。APK 签名、启动入口、版本、离线数据、13 个音效及无损循环音乐资源校验通过，包内不含试听版和开发资料。
