# 太阳系漫游 · 界面音效设计 v1

状态：用户确认采用；v0.19.0 已接入 13 种原创音效。Android 真机响度与延迟待试听。

目标是让声音说明操作结果，延续深蓝、青蓝界面的轻盈科技感。采用短促柔和的电子音、微弱气流和少量上行音阶。声音不是天体的真实发声，不为每颗行星添加拟真环境声。不配背景音乐、启动音乐或语音。

## 声音词汇

所有页面共用这一组声音。时长为试听文件时长；强弱仍需在安卓平板扬声器与耳机上校准，不能仅凭文件峰值判断实际响度。

| 编号 / 文件 | 含义 | 听感 | 时长 |
| --- | --- | --- | --- |
| 01 tap | 轻触、打开选择框或弹层 | 很轻的圆润点音 | 80 ms |
| 02 navigate | 进入另一页面 | 短上行音，少量空气感 | 190 ms |
| 03 back | 返回、关闭弹层 | 短下行音，收尾干净 | 160 ms |
| 04 select | 更换选项或对象 | 清晰但轻的单音 | 100 ms |
| 05 toggle_on | 开启、展开、开始播放 | 轻柔两音上行 | 150 ms |
| 06 toggle_off | 关闭、收起、暂停 | 相同两音下行 | 150 ms |
| 07 focus | 进入行星近景 | 柔和靠近感，比导航略厚 | 210 ms |
| 08 swap | 交换 A/B 比较对象 | 两个短音交错 | 190 ms |
| 09 adjust | 按钮缩放、时间轴落点 | 更轻、更短的刻度音 | 55 ms |
| 10 correct | 回答正确，但尚未完成全部实验条件 | 柔和三音上行 | 360 ms |
| 11 retry | 答错，鼓励重试 | 低柔双音，不用警报或蜂鸣 | 230 ms |
| 12 complete | 首次完成一个实验或学习任务 | 克制的四音上行 | 570 ms |
| 13 reset | 确认重置、实验归零 | 短促下行并稳定落地 | 210 ms |

## 结果音与完成判定

- 答案错误：播放 11，同时保留暖色提示与解释，声音不承担唯一反馈。
- 答案正确但尚缺实验条件：播放 10。例如四季题答对，但尚未完成观察或零倾角对照；不能误播完成音。
- 本次操作首次形成完成记录：只播放 12，替代 10 或任何点击声。
- 公转播放到终点、或手动拖到终点首次完成：只播放一次 12。后台不播放，回前台不补播。
- 同一道题重复点同一个已提交答案不响；更换答案后仍按当前结果提示。学习记录已有完成标志时，不重复发放完成音。
- 一次操作优先级：首次完成 > 答题结果 > 专用动作（交换、近景、重置）> 页面导航 > 选择/开关 > 轻触。

## 安静区域与声音控制

拖动旋转、双指缩放、滚轮缩放、页面滚动、鼠标悬停、键盘焦点移动、程序自动选中、初始化、读取存档和动画逐帧更新均保持静音。连续操作不循环播放“宇宙环境音”。

建议提供一个小型扬声器开关，放在全局导航末尾，手机仍保持导航不换行；若宽度不足，则与品牌放同一行右侧。开关至少 44×44 逻辑像素，显示“声音开启/已静音”的无障碍标签。本方案不恢复设置页面。

默认低音量开启，遵循设备媒体音量；偏好只存在本机。关闭立即停止现有声音且不再播放关音，开启播放一次轻触试听。实验重置和学习记录重置不改变声音偏好。后台立即停止，恢复前台不补播积压声音。

## Godot 接入设计

新增常驻 UI 音效服务和独立 UI_SFX 音频总线，预加载短音，避免每次点击临时加载。导航销毁页面不会截断已经触发的短音。首版控制为一个短音通道加一个结果音通道；同一操作只允许一个事件，结果音替换该操作的普通点击音，不将整串历史点击排队。

调用点位于已经接受用户操作的动作入口，带动作来源（user/programmatic）及前后状态比较。不要在 navigate、select_body、value_changed 或页面重建中无条件发声：这些方法也会被初始化与联动调用。触摸与模拟鼠标事件合并为一次有效动作；按下后拖出取消不能发声。

试听和设计资料位于 docs/design/audio-v1；13 个选定单项 WAV 已复制到 assets/audio。安装包不包含试听串或设计文档。试听规格 48 kHz、16-bit、单声道，短淡入淡出；音量为设计初稿，平台实际延迟和可听度由真机试听确定。

## 验收清单

1. 每个表列入口可触发对应主音，鼠标与触屏不重复。
2. 一次点击引起切页、选中、视角变化时只响一次；交换对象也只响一次。
3. 同值选择、取消、禁用按钮、初始化、恢复记录、滚动和连续手势静音。
4. 正确答案不等于实验完成时，不能播放完成音；已有完成记录不重复奖励。
5. 时间轴松手只响一次；缩放按键有节流，极限处静音。
6. 静音立即生效、重启保留；切后台停止，回来不补播。
7. 使用安卓平板扬声器和耳机分别核对轻音可听度、结果音强弱与点击延迟。
8. 界面仍保留所有文字与视觉反馈，关闭声音后任务完整可用。

## 试听方法

打开 audition.wav，按 01→13 的顺序播放，每个音重复两遍；完整约 28.6 秒。单项文件可独立试听。manifest.json 记录起始时间、时长和峰值。候选音效由 tools/design_ui_audio.py 原创程序合成，没有引入第三方素材。已做文件格式、时长、样本与削波检查；尚未进行真机试听。
