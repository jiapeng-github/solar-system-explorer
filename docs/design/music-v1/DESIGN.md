# 背景音乐设计：《星海慢航》

状态：用户确认接入，v0.20.0 使用循环原版；试听版仍作为独立设计资料保留。

## 听感与结构

轻柔、安静、有探索感的太空氛围音乐。温暖的持续和弦作底，少量玻璃琴般的音符点缀，留出长短不一的空隙。不使用鼓点、人声、警报或持续的高频噪声，适合探索行星、阅读知识卡和观察实验。

60 秒循环，内部速度参考 64 BPM，四个四小节段落：Cmaj9 → Am9 → Fmaj9 → Gsus2(add6)。和弦缓慢交叠，首尾延迟尾音环形衔接。立体声带少量交叉混合，避免声音只停留在耳机两侧；合并单声道的 RMS 约下降 1.33 dB。

旋律保持稀疏，主体能量集中于较低频段；与点击音效有部分频率交叠，接入时依靠音量层次及短暂压低背景音乐保持操作提示清晰。

## 文件

- `starlight-voyage-preview.wav`：60 秒试听，开头 0.7 秒淡入、结尾 1.5 秒淡出。
- `starlight-voyage-loop.wav`：无首尾淡入淡出的循环原版，接入时由播放器控制淡入淡出。
- `VALIDATION.json`：规格、峰值、RMS、接缝与单声道检查。
- 生成脚本：`tools/design_background_music.py`。全部由振荡器与延迟程序合成，不含外部采样。

48 kHz / PCM16 / 双声道，原版峰值约 -16.38 dBFS，RMS -30 dBFS，无削波。首尾边界两通道相邻采样差均为 1 个 PCM16 单位，低于曲内正常变化幅度。上述为文件检查，尚未进行安卓平板扬声器和耳机试听。

## 已采用的接入方式

首页进入时渐入约 1.5 秒。切换页面保持播放位置，不重新从头开始；所有页面使用同一音乐。播放器额外衰减 7 dB，确保明显低于操作反馈。答题结果和完成提示期间再短暂压低约 4 dB，随后柔和恢复。

沿用顶部声音开关控制静音。切入后台立即停止输出并保留位置，回到前台渐入续播。关闭声音后无音乐和点击提示，视觉反馈保持完整。最终音量需在安卓平板上根据真实听感调整。
