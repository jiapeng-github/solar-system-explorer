# v0.5.0 · 学习流程与平板操作完善

- 公转演示增加走过的轨迹、逆时针方向箭头及月份刻度。刻度表示示意经过时长，不对应真实日期。
- 昼夜实验明确 A 点是同一地点，答案选中可见；实验完成展示知识总结、下一站与学习进度入口。
- 昼夜、公转分别保留角度和答案；切换页面暂停播放，返回继续操作。重置清除当前尝试，不删除已完成记录。
- 页面历史返回优先关闭说明弹窗；实验、比较和滚动位置在本次运行内保留。关闭应用后保留的仍是原有学习完成记录和探索记录。
- 滑杆触控区域增大、刻度与青色进度条统一；按钮增加禁用状态；手机导航四入口同排，主要内容纵向滚动。
- 修复整数滑杆导致高帧率播放停滞，以及接近终点时舍入导致提前停止的问题；应用切到后台时暂停实验，回到前台需手动继续。

## 验证
Godot 4.6.3 桌面图形回归通过，覆盖原有轨道、相机、数据与存储流程，以及 60 fps 角度推进、暂停/重置、后台暂停、精确到达终点、两实验独立状态、完成总结、返回和比较状态保留。
检查横屏及手机窄屏实际渲染。相机收敛检查采用确定时间步，避免自动化窗口焦点干扰；不以此证明设备帧率。
Android 调试包的版本、ARM64、离线素材、包结构与签名验证见 BUILD_VERIFICATION_V0.5.0.json。
