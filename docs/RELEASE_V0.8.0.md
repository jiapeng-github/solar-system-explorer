# v0.8.0 · 概念图视觉还原

## 修改
- 统一深蓝半透明面板、青色渐变圆角主按钮和选中描边；设置中集中画质与资料说明，返回键仅在知识、进度页显示，系统返回流程保留。
- 程序化星云与星点增加背景层次；背景纹理初始化后缓存，无需联网或持续生成。
- 探索：调整相机默认近景、地球海洋色与明暗过渡、月球示意位置；合并播放/倍速/轨道/视角工具栏；放大缩略图并增加圆形选中光圈。
- 首页：放大标题与土星、调整环的视角；图文横向活动卡；紧凑进度区域，手机纵向堆叠。
- 实验室：太阳程序纹理与光晕、旋转箭头、统一角度和播放控制台、0/180/360 度刻度，答案选中提示。公转使用百分比刻度。
- 比较：放大比值，A/B 徽标（相同对象显示 AB）、选择器间交换按钮、测量线端点、小天体引线和千位分隔。
- 知识卡、进度及设置沿用公共样式。抽出 visual_style、selection_overlay 和 angle_slider 组件。

## 验证
完整功能回归通过：探索、相机手势、实验、学习任务、旧记录兼容、重置确认、三档画质、静态首页与连续切页资源检查。
新增 tests/visual_review.gd：固定状态生成四页截图，1280×800 和 1280×720 核心内容可在首屏呈现；五个手机页面保持实际视口宽度。发现并修复手机首页统计文字撑宽页面的问题。
截图测试主动请求一帧绘制，避免按需渲染的静态页面等待绘制信号超时。
Android 包结构、资源与签名见 BUILD_VERIFICATION_V0.8.0.json。

## 还原边界
构图与组件以已确认概念图为参考；实时材质、程序化星空和现有授权贴图仍与生图的摄影质感存在差异，不宣称像素级一致。
保留进度和知识入口，比较图继续严格遵守真实直径比例。没有添加未经授权的新外部素材，也未将整张概念图用作交互页面背景。
安卓平板真机帧率、发热和触控体验按要求暂缓验收；iOS 未构建签名。
