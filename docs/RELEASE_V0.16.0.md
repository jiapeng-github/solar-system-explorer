# v0.16.0 · 全界面检查与优化

## 已修复

- 手机主导航收拢为一行，品牌与知识卡返回按钮放在同一行，减少顶部占用；全站星云背景保持比例，避免竖屏拉伸。
- 公转实验起点/终点文字移到地球上方，避免被球体遮住；公转比较页不再误用“气态行星采用代表值”的自转说明。
- 安卓返回键优先关闭答题卡及顶层弹窗，不误退出进度页。Tab、Shift-Tab 和方向键循环限制在答题卡内，关闭后恢复有效焦点；答题导致页面重建时不会恢复到已销毁的按钮。
- 答题按钮和关闭按钮至少 44×44 逻辑像素，手机进度页实验、任务和重置按钮增高。
- 学习记录重置后同步恢复地球选择与全部行星区域；相机在探索视图重新挂载后恢复，避免在已卸载的视口上调用相机。
- 首页及进度页补回“资料与模型说明”入口，继续默认高清且不增加设置入口。
- 资料说明和重置确认改为深蓝应用内卡片。资料说明支持滚动且关闭按钮固定可见；重置默认聚焦“保留记录”。
