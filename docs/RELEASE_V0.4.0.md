# v0.4.0 · 三个页面设计落地

## 功能
- 出发页：深蓝星空、独立 3D 土星展示、继续探索入口、已探索行星和已完成实验进度、三张活动卡。
- 实验室：自转与昼夜、公转与一年；拖动角度、播放、暂停、重置；地球贴图球面和固定方向光照；答题反馈与本地完成记录。
- 比较页：A/B 对象选择、八颗行星缩略图、交换对象；球体按平均直径同比例绘制；真实半径数据与比值；轨道半长轴距离比较。
- 横屏双栏、竖屏堆叠，手机内容可滚动。保留现有探索页及镜头行为。

## 验证
Godot 4.6.3 桌面图形回归通过：科学参数、存储、导航、镜头、实验播放/暂停/重置、完成记录、比较比例、交换和缩略图选择、横竖屏布局。
已目视检查首页、昼夜实验、比较页与手机比较布局的实际渲染截图。
Android ARM64 调试安装包使用包结构、资源和签名验证，结果见 BUILD_VERIFICATION_V0.4.0.json。

## 范围
这是可操作的设计实现，视觉以 Godot 实时渲染为准，与生图概念中的光晕、纹理细节不完全一致。
按用户要求跳过本轮安卓平板真机调试，触控、实际帧率及设备兼容性仍待验收。iOS 未构建和签名。
实验为教学简化模型；探索大小与间距为示意，比较页大小图按平均直径比例展示。素材许可沿用 ASSET_CREDITS.md。
