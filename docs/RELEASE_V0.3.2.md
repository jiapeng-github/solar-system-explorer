# v0.3.2 镜头与操作体验

本次按用户要求跳过安卓真机调试，继续完成桌面可验证的交互开发。

- 行星切换、近景与全景切换采用约 0.6 秒平滑过渡，角度走最短路径，距离采用对数插值。
- 动画期间可以拖动接管镜头，接管瞬间保持当前可见相机位置；连续切换从当前画面开始新的过渡。
- 新增“恢复视角”：近景恢复当前行星的推荐观察角度与距离，全景恢复整体取景。
- 近景缩放上下限按天体／土星环尺寸设置；全景按整体轨道范围设置，避免误操作无限拉远。
- 返回全景时渐进增强小天体的显示尺寸，避免尚未离开近景时行星突然放大。
- 保留上版轨道间距、标签避让、选中轨道高亮与离线科普内容。
