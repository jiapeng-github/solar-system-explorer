# v0.10.0 · 全景探索重构

## 效果图落实
参考 docs/design/overview-concept-v2.png，将标题移出 3D 视口，扩大轨道展示区，压缩右侧资料卡，保留顶部导航和底部八行星选择条。选框包含缩略图及名称。

全景使用等距投影与较低俯视角，独立增大行星显示尺寸，增加观察用补光、连续轨道和标签引线。内圈轨道显示间距重新分配，采用错开的任意初始相位。物理参数、运行周期和真实比例比较数据保持不变；全景仍为大小与距离示意。

## 交互
- 全部行星、内太阳系、外太阳系切换；分区内自动选择可见行星，资料卡同步。
- 全景中底部缩略图更新选择；选择区域外的行星时恢复全部视图，避免对象不可见。
- 点击场景行星或“进入近景”查看特写；近景保留透视投影。
- ＋／−、鼠标滚轮、触控板缩放手势、双指捏合控制缩放，设定缩放上下限；恢复视角保留当前分区或近景对象。
- 暂停／继续、倍速、轨道开关、知识卡和学习记录保持可用。

## 验证
完整功能回归通过，新增全景投影、缩放上下限、恢复视角、四行星分区、选中对象可见性和近景切换断言。
截图与布局检查覆盖平板 1280×800、1280×720 和手机窄屏；新增 tests/overview_review.gd 保存全景、分区和缩放状态截图。其他主页面继续执行 tests/visual_review.gd。
Android 包校验结果见 BUILD_VERIFICATION_V0.10.0.json。

## 交付边界
界面按概念图布局实现，实时贴图、光照和程序化太阳材质仍与生图质感有差异。手机采用纵向滚动布局。Android 真机帧率、发热与双指触控体验仍待平板验收，本次提供 arm64 调试包；iOS 未构建签名。
