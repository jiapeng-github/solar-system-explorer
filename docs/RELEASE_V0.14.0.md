# v0.14.0 · 进度页效果图实现

依据 docs/design/progress-concept-v2.png 重做进度页，使用原生 Godot 控件与真实学习记录。

- 顶部展示行星、实验、任务三项统计及下一步推荐；八颗行星显示已探索、下一站、待探索状态。
- 三张互动实验卡片使用地球、太阳公转轨道、倾斜地轴插图，支持开始实验或再次查看。
- 两个学习任务展示行星缩略图、探索数量、指定比较及答题状态；已完成任务可查看收获。
- 推荐按任务进度引导补充行星探索、进入指定比较、回答验证问题，任务完成后推荐未完成实验；全部完成后可重访地球。
- 重置保留确认步骤。没有填入概念图中的固定示例数据，截图使用独立测试记录，不修改用户的学习记录。
- 横屏完整展示统计、足迹、实验、任务与底部操作；手机切换为纵向卡片和四列行星。

验证
- tests/progress_tests.gd：推荐跳转、行星状态、三个实验入口、答题条件、错误/正确回答、完成复习、重置确认、空记录及全部完成状态。
- 1584×992、1280×800、1280×720 首屏布局通过；390×844 手机无横向溢出。
- tests/run_tests.gd：全应用功能回归通过，包括探索相机、近景、缩放、实验播放、比较、学习任务、记录恢复。
- APK：Android arm64，版本 0.14.0，versionCode 20；包结构和签名校验见 BUILD_VERIFICATION_V0.14.0.json。

实际渲染截图：progress-v014-reference.png。布局、状态配色和内容结构依据设计稿实现；原有行星纹理、实时材质与字体仍有细节差异。测试在桌面 Godot 4.6.3 完成，安卓平板真机触控和性能尚待验收。
