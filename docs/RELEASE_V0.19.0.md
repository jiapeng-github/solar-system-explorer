# v0.19.0 · 全界面交互音效

按已确认的设计接入 13 种原创短音：轻触、导航、返回、选择、开启、关闭、近景、交换、调整、答对、重试、完成、重置。覆盖出发、探索、三个实验、比较、知识卡、进度、答题与资料/重置弹层。

## 使用方式

- 默认低音量开启，遵循设备媒体音量。平板导航右侧提供扬声器按钮；窄屏移到品牌行右侧，触摸区域至少 44×44。
- 关闭声音立即停止播放；重新开启发出一次轻触试听。偏好保存在本机 `user://audio.cfg`，不受学习记录重置影响。
- 点击当前页面、当前选择或已提交的相同答案保持安静。触控/鼠标拖动旋转、双指与滚轮缩放、页面滚动和悬停不播放声音。
- 时间轴只在有变化的松手或键盘调整后提示。缩放按钮节流 100 ms，达到边界不响。
- 答错使用柔和重试音；答对但条件不足使用答对音；首次完成实验或任务时，完成音取代普通点击与答对音。恢复记录和重访已完成项目不播放奖励。
- 离开前台或 Android 暂停时停止音效与实验播放；回前台不补播。

## 实现

`scripts/ui_audio.gd` 常驻服务预载 13 个 PCM16 / 48 kHz / 单声道 WAV，使用独立 UI_SFX 总线和两个播放通道。同轮操作按完成、答题结果、专用动作、导航、选择、轻触的优先级合并。声音资源沿用确认稿，播放器额外衰减 2 dB。无新增权限、在线依赖、背景音乐或语音。

按钮在接受用户操作时请求反馈，程序初始化、联动选中和 UI 重建不请求音效。全局 Escape/Android 返回与可见弹层返回统一反馈。重复点击当前实验页签或四季当前参数，不会意外暂停或重建页面。

## 验证

验证日志保存在 `work/`，安装包验证结果见 `BUILD_VERIFICATION_V0.19.0.json`。测试使用独立的学习、画质与声音偏好文件，不改用户记录。

- 音效服务：优先级、去重、节流、静音持久化、前后台、滑杆释放/键盘及音频规格。
- 实验室：用户操作边界、重复选项、答对但条件不足、首次完成、时间轴释放、播放完成、Android 暂停/恢复。
- 全界面联动：导航、行星与区域联动、缩放边界、速度、两处比较交换、知识卡、答题刷新、静音与重置。
- 实际桌面渲染：平板横屏、平板竖屏和手机布局中的全局声音开关；截图 `work/audio-home-tablet.png`、`work/audio-home-800.png`、`work/audio-home-390.png`。

Android 版本 0.19.0，versionCode 26，arm64 debug APK。原始 WAV 共约 255 KB（255,452 字节），编译音频随包离线使用。Android 真机扬声器、耳机响度及触控到发声的延迟仍需现场试听，桌面检查不替代真机验收。

音效服务、实验室、全应用回归、四季渲染、答题键盘/焦点、全页音效实际渲染六组检查均通过，日志无脚本错误或资源残留警告。验证摘要见 `AUDIO_VERIFICATION_V0.19.0.json`。APK 校验通过：启动入口、版本、arm64、无额外权限、签名、离线数据与贴图、13 个编译音效；无开发测试文件与试听串。
