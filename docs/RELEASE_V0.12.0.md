# v0.12.0 · 公转与一年效果图实现

根据 docs/design/year-concept-v2.png 重做实验室公转页。

- 左侧采用同排标题与连续实验切换、大幅投影轨道及底部独立控制台；右侧为贯穿页面的实验说明卡。
- 单颗地球沿轨道逆时针运动，青色弧线表示已经走过的轨迹，起点由虚线圆环标出，12个刻度表示近似月份。
- 公转进度、已用时间、轨迹和当前位置实时联动。四分之一圈为25%、约3个月、约91天。模型按365.26天计算一圈，知识卡使用“约365天”的近似表述。
- 还原步骤圆环、青色提示框、金色一年知识卡、锁定的下一实验入口、主按钮和重置按钮。
- 完整一圈后保存完成记录并解锁下一实验；支持重播、拖动暂停、后台暂停和重置。重置演示不会清除学习记录。
- 独立太阳纹理、光晕、地球云层与大气，以及低对比星云背景；轨道底部标签避开太阳名称。
- 手机自动纵向排列。保留原有昼夜、四季实验和探索、比较功能。
