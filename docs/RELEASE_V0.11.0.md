# v0.11.0 · 四季与地轴

实验室新增第三个实验，按 seasons-functional-design-v1.txt 与 seasons-concept-v1.png 实现。

功能
- 点选四个分日至日位置、拖动完整0—360°时间轴、播放/暂停/重置。终点为下一次三月分日，手动操作和进入后台会暂停。
- 南北纬40°切换，显示季节、几何昼长与正午太阳高度；赤纬由公转相位和倾角统一计算。
- 默认23.4°倾角，0°假设对照下固定纬度日照指标全年不变。四个地球采用相同世界坐标地轴与朝向太阳的光照；播放时额外显示当前位置。
- 观察四个位置、体验不倾斜对照且答对问题后完成。答错可重试，播放一圈不会单独完成。
- 进度保留位置、半球、倾角、步骤、答案与观察记录。首页和进度页显示三项实验，旧昼夜和公转完成记录保持兼容；原有两条学习任务规则不变。

验证
- tests/seasons_tests.gd：分日昼长、南北半球至日对称、0°不变性、完成条件、手动/后台暂停、全年终点、切页/重启恢复、重置与横竖屏布局。
- tests/run_tests.gd：全应用功能回归。
- tests/visual_review.gd：其他主要页面布局回归。
- APK校验结果见 BUILD_VERIFICATION_V0.11.0.json。

模型边界
圆形匀速共面公转的教学模型，不对应具体年份。大小与距离为示意，昼长忽略折射和太阳视半径，不推算当地气温。地轴倾角针对四季实验，探索场景不因此变为真实星历。
实时渲染材质与生图质感仍有差异。安卓平板真机性能与触控验收待进行，本次交付arm64调试包。
