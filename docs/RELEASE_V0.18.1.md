# v0.18.1 · 图标可见尺寸校正

上一版按非零 alpha 边界归一化，生图中的极低透明度像素导致边界虚大，实际圆角底板被二次缩小。现按 alpha ≥ 0.1 的可见边界归一化，并保留抗锯齿边缘。

1024×1024 资源实测：
- 修复前：alpha ≥ 0.5 轮廓 645×635。
- 修复后：alpha ≥ 0.5 轮廓 831×818，alpha ≥ 0.1 轮廓 832×819。
- 按截图中128像素图标画布估算，可见宽度从80.6调整到103.9像素，接近相邻图标约104像素。

保留圆角设计、透明留白和顶部标志；Android自适应前景安全区不变。具体 Dock 显示需重新启动应用确认。

资源尺寸检查和APK校验通过。Android版本0.18.1，versionCode 25。
