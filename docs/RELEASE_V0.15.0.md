# v0.15.0 · 统一答题界面

- 学习任务移除系统 AcceptDialog 灰色窗口，改为应用内深蓝圆角卡片、半透明遮罩、关闭和返回入口。宽度限制为 620 逻辑像素，按内容收缩，高度不足时内部滚动。
- 岩石行星、巨行星任务答错后保留题目及选项，用暖黄色标识错误选择并给出提示；答对后展示任务收获。保留原有任务完成条件和本地记录。
- 昼夜及四季实验使用相同的 A/B/C 选项、大点击区域、自动换行、焦点边框和正确/待重试状态。修复昼夜实验把错误选择也标成勾的问题。
- 关闭答题或完成复习可返回原进度页；支持 Escape 关闭任务答题卡。

验证：tests/quiz_tests.gd 检查两道任务题的错误/正确反馈、关闭、复习，以及 1584×992、1280×720、390×844、844×390 的弹层边界与选项宽度；检查昼夜错误标识和四季错误回答不完成实验。tests/progress_tests.gd 和 tests/run_tests.gd 覆盖进度与全应用回归。

Android 0.15.0 / versionCode 21；APK 资源、架构、版本及签名校验见 BUILD_VERIFICATION_V0.15.0.json。以上为桌面 Godot 验证，安卓平板真机触控及性能仍待验收。
